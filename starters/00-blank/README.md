# 00 — Blank Starter

Baseline Nuxt 4.4.8 project. This is the starting point for the nuxtlearn syllabus.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What's Here

- `app.vue` — Single root component (no pages/ yet)
- `nuxt.config.ts` — Minimal config with devtools enabled
- Nothing else — intentionally minimal
