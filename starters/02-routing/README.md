# 02 — Routing

File-based routing with dynamic parameters using `pages/` directory.

## What to explore

- Adding a file to `pages/` automatically creates a route
- `[id].vue` syntax for dynamic segments
- `useRoute()` to access params
- `<NuxtLink>` for client-side navigation (prefetching on hover)

## Run

```bash
npm install
npm run dev
```

Visit `/`, `/about`, `/posts`, `/posts/1`.
